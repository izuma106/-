# -🏐 Volleyball Club Management System
📌 Описание
Консольное Java-приложение для управления волейбольным клубом.
Позволяет добавлять игроков и тренеров, создавать команды, назначать тренеров, переводить игроков между командами.

🛠 Технологии
Java 21
ООП (классы, наследование, полиморфизм, инкапсуляция)
Интерфейсы и абстрактные классы
Обработка исключений
🗂 Структура проекта
VolleyballClub/
├── src/
│   ├── Person.java          # Абстрактный класс (суперкласс)
│   ├── Player.java          # Наследует Person, реализует Transferable
│   ├── Coach.java           # Наследует Person
│   ├── Transferable.java    # Интерфейс для трансфера игроков
│   ├── Team.java            # Класс команды
│   ├── Club.java            # Класс клуба
│   └── Main.java            # Точка входа + меню
└── README.md
🏗 Архитектура (ООП)
Принцип	Где применяется
Инкапсуляция	Все поля private, доступ через getter/setter
Наследование	Person → Player, Person → Coach
Полиморфизм	getRole() переопределён в Player и Coach
Абстрактный класс	Person с абстрактным методом getRole()
Интерфейс	Transferable — метод transfer() и getTransferInfo()
Исключения	Проверка возраста, дубликатов номеров, ненайденных объектов
🚀 Как запустить
# 1. Скомпилировать
javac -d out src/*.java

# 2. Запустить
java -cp out Main
